> 在 Claude Code 里，LongPi 的工具名是 `mcp__longpi__<名字>`；下面只写名字。LongPi 的页面用 `/longpi` 打开（总览、化验、睡眠、运动、日程、方案、长寿图鉴、档案、设置）。

# 把资料收进来

LongPi 的记录存在这台电脑上（`~/.longpi`），只来自对方交给你的资料和对方自己量的数。

## 体检报告、化验单（PDF 或照片）

1. 用 Read 打开对方给的文件（路径，或拖进对话的附件）。多页报告逐页读，不要漏页。
2. 用 `record_measurements` 一次录入一份报告：`date` 是采样或报告日期；每一项照报告原样写名称、数值（保留 ↑↓、阴性、<0.5 这类写法）、单位，单子上有参考范围就写 `ref_low` / `ref_high`。只有确定时才写 LOINC 编码。不要换算单位，不要估一个值，看不清的就问对方。彩超、CT、X 线、心电图、眼底这些检查结论也一样录，数值写报告原话。报告是电脑上的 PDF 时，把它的绝对路径传给 `report`：LongPi 会核对报告每一页，把还没录的项目列在 `not_filed` 里，照着补录（同一日期），断行造成的半个名字补成完整项目。
3. 录完用一两句话说：录了哪一天、多少项、有哪几项标了异常。不要把整张表念一遍。
4. 再调一次 `read_personal_situation`：记录变了，身体年龄、心血管风险、值得注意的变化和下一步可能都变了。
5. 报告上不是本人的姓名：先问清是不是本人的；是家人的，请对方在 LongPi「总览」顶部的「在看」切换到那位家人再录。不要说出报告上的姓名。

## 手环、体重秤、血压计、App 导出

消费级基因检测报告（微基因这类叙述版 PDF，常有几千页）：用 `import_genetic_report`，`report` 是 PDF 的绝对路径。它在本机只打开和关键位点有关的几十页（APOE、叶酸、酒精、乳糖、咖啡因、痛风、他汀、华法林、氯吡格雷、阿司匹林、二甲双胍），不要自己把整本读进来。读回时说保存了哪些位点和第一条局限；不要把位点说成诊断、化验异常的原因、补剂或剂量。

iPhone 的 Apple 健康导出（健康 App → 头像 → 导出所有健康数据，得到 export.zip）：直接用 `import_apple_health`，`export` 是 export.zip、export.xml 或解压后文件夹的绝对路径，在本机转换，不上传。

其他手环和 App（华为、小米、Garmin 等）的导出文件（CSV、XML、JSON 都行）先写成一个 CSV：表头 `date,name,value,unit`，可选 `loinc,ref_low,ref_high,time`，一行一个数值，名称和数值照导出原样。每天的手环指标尽量用这些名字：`dailySteps`（步数）、`restingHeartRate`（静息心率）、`hrvRmssd`（心率变异性）、`sleepDuration`（睡眠时长，单位写 h 或 min）、`sleepStartTime`、`sleepEndTime`。写好后用 `import_measurements_csv`，`path` 是 CSV 的绝对路径。长寿图鉴的实验靠这些每日数据判断结果。

对方自己量的腰围、家庭血压、体重：用 `save_self_measurement`，单位照对方说的传。

## 叙述

超声的 TI-RADS、BI-RADS、总检和医师建议不在检验数字里。读报告时把这些句子原样告诉对方，`read_narrative_findings` 能读到已经记下的。分级是报告上的分级：建议带给医生，不判断穿刺或手术。

## 用药和诊断

对方说「请记一下」某种药：用 `record_medication_statement`，照抄药名、剂量和次数，然后把 `read_back` 说回去。不建议加减药。
对方说自己有某种病或医生的诊断：用 `record_condition`，记在这台电脑上。复述 `read_back`。这不是确认诊断。

## 甲基化、菌群、蛋白、诊断编码

这类表不是体检数字。`forward_report` 带 `type`：`methylation`、`taxa`、`proteins` 或 `conditions`，以及可选的 `sample_date` 和 `site`（`gut` 或 `oral`）。对方在对话里给了文件，就算确认。表留在这台电脑上，不送进体检记录，也不把整张表放进对话。时钟年龄（单位是岁）不是甲基化 β 值。

## 基因

消费级基因报告（如微基因的叙述版 PDF，上千页）不要整本读进对话，也不要贴全文。对方问到哪个位点（如 APOE），就只找那几页读，并说明这是消费级报告、不是诊断、不能据此换药。原始数据文本（文件开头是 `# This data file generated by WeGene at`）可以在对话里按位点查。
