# 论文、仓库、另一套同名东西

Nature Communications（2026），doi:10.1038/s41467-026-76240-w。全文用 pypdf 从 PDF 抽出。

| | 内容 |
| --- | --- |
| 论文声称 | 测到 17,959,684 个高质量 CpG。时钟用 1,373 个，训练中位绝对误差 2.22 年，测试集 2.43 年。其中 398 个（29.0%）高甲基化，975 个（71.0%）低甲基化。亲本来源在 Bonferroni p < 2.8×10−9 后有 1,274,315 个（7.1%）位点。DIRAS3 被描述为活性父本等位基因随年龄高甲基化，正文没有给出个人切点。系数在 Supplementary Data 3。 |
| 代码实际算 | 清单里的 `DecodeGenetics/graphtyper` 是基因分型工具，不是甲基化时钟。本技能没有克隆它。套索系数在 Supplementary Data 3，作用在标准化甲基化上；训练均值和标准差不在该表，所以不能把原始比例直接乘上这些系数。 |
| 同名的另一套 | 文中对照的 Horvath 时钟（训练 medAE 2.9 年，测试 3.6 年，353 个 CpG）和 Hannum 时钟（总体 medAE 3.9 年，测试 4.9 年，71 个 CpG）是别的时钟。 |
