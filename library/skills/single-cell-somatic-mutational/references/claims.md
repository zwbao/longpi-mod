# 论文、仓库、另一套同名东西

Ren 等，Nature Aging（2025），doi:10.1038/s43587-025-01011-z。全文用 pypdf 读本地 PDF。

| | 内容 |
| --- | --- |
| 论文声称 | 17 名供者、100 个软骨细胞。全体 SNV 每年 33 个（P = 0.0001），InDel 每年 5 个（P = 0.0078）。分组 SNV 斜率：非 OA 对照 56（P = 0.00418），OA 非病灶 26（P = 0.0407），OA 病灶 19（P = 0.0424）。负担 = 观察到的突变 /（覆盖比例 × 灵敏度）。灵敏度 ≥ 20% 且覆盖 ≥ 15% 才进入后续分析。 |
| 代码实际算 | `zhengchen98/OA-WGS-analysis` 用 `lmer(SNVADJ ~ age + (1\|patient))`。仓库没有 `.Rdata`，不能重拟合。部分代码块把 `SNVADJ/age` 再拿去比较，那不是论文主模型。本技能只实现方法节的负担公式，不把突变数除以年龄当成斜率。SCcaller 是调用变异的依赖，不是这篇的统计方法。 |
| 同名的另一套 | Sarek、BWA、GATK 是通用流程。SCcaller 是另一套变异调用工具。 |
