# Claims

The phenotypic-age calculator is Levine et al., Aging 2018 (doi:10.18632/aging.101414), as the unrounded `orig=TRUE` weights in `phenoage_calc.R` from `https://github.com/dayoonkwon/BioAge`. Gao et al., Nature Communications 2023 (doi:10.1038/s41467-023-38013-7, Europe PMC `PMC10119095`) uses phenotypic age for depression and anxiety and does not publish these coefficients. Its questionnaire cutoffs are applied only when that file is supplied. The BioAge repository is the Kwon and Belsky NHANES toolkit (GeroScience 2021). It is not the UK Biobank depression analysis, and this skill does not import a later port's Cox models.

| What the paper states | What the code computes | What is missing |
| --- | --- | --- |
| KDM-BA from FEV1, systolic blood pressure, albumin, alkaline phosphatase, blood urea nitrogen, creatinine, CRP, HbA1c, and total cholesterol. Reference: NHANES III, nonpregnant, ages 30–75, separate fits for men and women (Methods). | `kdm_calc.R` regresses each biomarker on age when `fit` is NULL and does not ship `q`, `k`, `s`, or `s_BA`. | No KDM number is produced. No substitute coefficients are stored. |
| PhenoAge from albumin, alkaline phosphatase, creatinine, CRP, glucose, mean cell volume, red cell distribution width, white blood cell count, and lymphocyte proportion (Methods). | `phenoage_calc.R` with `orig=TRUE` applies the unrounded Levine weights and `phenoage_advance = phenoage - age`. | The personal script uses those weights. |
| Methods prints `xb` with rounded coefficients and a typesetting gap (`-19.907-0.0336+albumin` omits the multiplication). Gamma is printed as 0.0076927. | The code uses `-19.90667`, albumin weight `-0.03359355`, and gamma `0.007692696`. | The reported age follows the code coefficients, which implement the same formula. |
| CRP enters as ln(CRP). | `data-raw/nhanes_all.R` sets `lncrp = log(1+crp)` and then multiplies that column by the Levine ln(CRP) weight. `phenoage_calc.R` does not take the log itself. | The reported age uses ln(CRP mg/dL), the printed equation. The NHANES log1p column is not applied to the user file. |
| NHANES cleaning also does `creat_umol = creat * 88.4017` after `creat * 0.960 - 0.184`, and `glucose_mmol = glucose * 0.0555`, `albumin_gL = albumin * 10`. | Those lines recode the survey file. | They are not applied to a user file. The user file is already in g/L, µmol/L, mmol/L, and mg/dL. |
| Age acceleration is the residual of biological age on chronological age, then standardized to mean 0 and SD 1 in the cohort (Methods). | The package also stores `phenoage_advance0 = phenoage0 - age`. Table 1's PhenoAge acceleration mean is −10.92, which is not a mean residual. | This script reports the advance (phenotypic age minus chronological age). It does not residualize and does not apply Table 3. |
| Table 3: PhenoAge acceleration and incident depression/anxiety, HR 1.113 (1.096–1.130), 16523/369745. | Not implemented in BioAge. | Quoted as a cohort result, not as this person's risk. |
| PHQ-4 total ≥6 for depression/anxiety, items 1–2 ≥3 for depression, items 3–4 ≥3 for anxiety. PHQ-9 or GAD-7 total ≥10 is positive; any item ≥1 is positive for that symptom. | Not in BioAge. | Applied only when the corresponding file is supplied. It does not change phenotypic age. |
| BMI is kg/m^2, then <25, 25 to <30, or ≥30. Healthy alcohol is <28 g/day for men and <14 g/day for women. Healthy activity is ≥150 min/week moderate, or ≥75 min/week vigorous, or 150 min/week mixed. Additional hypertension includes ≥140 mmHg SBP; the same sentence also says ≥90 mmHg SBP. | Not in BioAge. | Body mass, alcohol, activity, and SBP ≥140 are applied only when supplied. The repeated ≥90 mmHg SBP term is not applied. None of these change phenotypic age. |
| Childhood Trauma Screener: five items scored 0–5. Emotional, physical, and sexual abuse count when the answer is not “never true”. Emotional neglect counts for never/rarely/sometimes. Physical neglect counts unless the answer is “very often true”. | Not in BioAge. | Applied only when five answers are supplied. It does not change phenotypic age. |
| Homeostatic dysregulation is part of the BioAge README. | `hd_calc.R` can compute it. | This paper does not use it, so the script does not either. |

Checkup bounds are not taken from this paper. Labs are printed as supplied and do not edit the nine biomarkers.
