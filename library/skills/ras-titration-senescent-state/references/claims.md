# 论文、代码、另一套同名东西

Chan 等，Nature（2024），doi:10.1038/s41586-024-07797-z。全文来自 Europe PMC PMC11410659。JSON 里没有 GitHub。

| | 内容 |
| --- | --- |
| 论文声称 | 癌基因 RAS 剂量不是线性开关。RPE1 里按 mVenus 分成 N、S、M、L、XL。S 诱导后 SA-β-gal 没有显著升高并保持增殖；M、L、XL 的 SA-β-gal 显著升高，细胞周期相对未诱导对照下降（Fig. 2）。差异基因门槛是 FDR < 0.05 且绝对 log 倍数变化 > 1.2。肝脏里启动子强度 CAGGS > PGK > UBC（Fig. 3）。CAGGS-NRAS(G12V) 大约在注射后第 12–30 天被清除，第 9 天 CD4、CD8、NK、未成熟单核细胞和巨噬细胞增加。PGK 的免疫监视较弱，UBC 的免疫监视缺席，两档的免疫细胞募集都很少，并走向肿瘤。单细胞第 2 群是中间剂量的祖细胞样状态，文中举的基因是 Afp、Prom1、Dlk1；第 4 群是高剂量 OIS。 |
| 这份 Skill 实际算 | 把用户给出的箱名映到上述表型。不算表达量，也不拟合权重。箱名不在论文分组里就拒绝。 |
| 同名的另一套 | 各种 RAS 通路化合物库和抑制剂筛选。那些不是这篇的剂量分箱。 |
