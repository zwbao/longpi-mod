# 操作定义

DrugAge 综合分沿用 `longevityclaw/drugage.py` 的 `score_compound`。正的平均寿命变化除以 100 后截到 1；负的除以 50 后截到 -1。物种数每多一个加 0.05，最多 0.2。ITP 记录加 0.15。正向实验比例乘 0.1。总和截到 0 和 1 之间，再四舍五入到四位小数。排序要求至少两项实验。

向量场沿用 `longevityclaw/control_laws.py`。12 个 Lopez-Otin 标志、八个写死的干预、典型状态从 20 岁到 100 岁线性插值。`biological_age` 是控制代价。贪心顺序在再下降不超过 0 时停止。Lie 括号是两个效应相乘再乘 0.5，报告不把括号值当成协同用药建议。

年龄默认 50，与仓库 `control_law_analysis` 的默认值相同。体检表只识别谷丙转氨酶、谷草转氨酶、肌酐、肾小球滤过率、血红蛋白、血小板。

现用药用别名对齐 DrugAge 显示名。阿司匹林肠溶片对齐阿司匹林。烟酸没有单独的别名，对不上就写名单里没有。
