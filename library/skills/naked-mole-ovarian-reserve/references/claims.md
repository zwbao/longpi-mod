# 论文、补充表、代码、另一套同名东西

Brieño-Enríquez 等，Nature Communications（2023），doi:10.1038/s41467-023-36284-8。

| | 内容 |
| --- | --- |
| 论文声称 | 生殖细胞数在 P5 到 P8 之间显著增加，P8 每对卵巢约 1500000 个生殖细胞。计数先把每 20 张切片计一次的总数除以所计切片数，再乘总切片数，然后除以校正因子。P1、P5、P8 的校正因子是 1.5，P28 是 2.0，P90、P6MO 和成年是 2.5。每 10 张与每 20 张切片的平均相差 3.1%。 |
| 补充表里实际有什么 | Supplementary Data 19 是各染色、各日龄、每只动物已经算好的细胞总数，例如 VASA 在 P8 的第一行是 1454544。表里没有单独的校正因子列，也没有把 P15 的因子单列出来。 |
| 代码仓库实际算什么 | 论文没有给出代码仓库。计数用 Fiji 的 cell counter，公式写在正文方法里。 |
| 同名的另一个项目是什么 | 小鼠卵子发生主要在胚胎期完成。这篇写的是裸鼹鼠出生后仍保留的生殖细胞。 |

1500000 和各只动物的计数留在这里，不写进个人报告。
