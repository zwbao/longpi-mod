| 论文声称 | AmiAge 用随机森林，18 个氨基酸加 18 个比例，年龄 1–89 岁。训练集 4,529 人（80%），测试集 1,130 人。Fig. 2c 测试集 r = 0.90，R² = 0.80，RMSE = 10.30，MAE = 7.53。年龄偏差校正后 Fig. 2d 为 r = 0.94，R² = 0.86，RMSE = 8.66，MAE = 6.73。简化模型的 8 个氨基酸是丙氨酸、谷氨酰胺、甘氨酸、组氨酸、亮氨酸、苯丙氨酸、酪氨酸、缬氨酸。另外 10 个氨基酸的名字在 Table S2，不在抽出的正文里。 |
| 这份 Skill 实际算 | 八个都给出时，每个浓度除以这八个的和。这是简化模型写的「各自除以总浓度」。缺任何一个就不算，不用已提供成员的部分和冒充分母，也不用未读到的 18 个之和。 |
