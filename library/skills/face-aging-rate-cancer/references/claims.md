| 论文声称 | FAR 是两次 FaceAge 之差除以两次照片的时间间隔。FAR 大于 1 被定义为快于历法时间。生存分析另用分档的界：短间隔 FAR > 20，中间隔 FAR > 10，长间隔 FAR > 1。2,276 名接受至少两次放疗的肿瘤患者，首次放疗年龄中位数 63.4 岁，照片间隔中位数 286 天，随访中位数 35.7 个月。Fig. 3 的 Cox 检验集：短间隔 10–365 天 n = 908，完全调整风险比 1.25（1.03–1.51）；中间隔 366–730 天 n = 549，1.37（1.00–1.86）；长间隔 731–1,460 天 n = 365，1.65（1.22–2.22）。Fig. 2b 短间隔分布的 n 是 1,362，和 908 不是同一格。短间隔 FAR 范围 −648.5 到 368.2，中间隔 −26.2 到 29.5，长间隔 −10.0 到 14.7。FaceAge 偏差的中位数在第一次是 0.99 年，第二次是 1.85 年。 |
| 这份 Skill 实际算 | FAR = (第二次 FaceAge − 第一次 FaceAge) / (天数 / 365.25)。365.25 是为了让“大于 1”对应快于历法年，正文没有写清分母用 365 还是 365.25。天数按 Fig. 3 的日区间分类后，对照该档印出的界。区间外不算这个对照，也不引用风险比。风险比留在名单里时写明它不是按本次 FAR 换算的个人风险。 |
| 代码实际算 | `AIM-Harvard/FAHR-Face` 是基础模型、年龄估计和生存模型的训练与推理。README 写明权重尚未放出。`run.py` 没有 FAR 这个函数。 |
| 同名的另一套 | arXiv:2506.14909 是 FAHR-Face 本身。本篇是用已有 FaceAge 做纵向速率和肿瘤生存，Cox 模型不在那个仓库里。 |
