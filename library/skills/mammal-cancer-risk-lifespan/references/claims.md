# 论文、补充表、代码、另一套同名东西

Vincze 等，Nature（2022），doi:10.1038/s41586-021-04224-5。

| | 内容 |
| --- | --- |
| 论文声称 | 110148 只成年动物园哺乳动物、191 个物种，其中 11840 只有死后病理记录。癌症死亡比例 CMR 是癌症相关死亡除以有病理记录的死亡。考瓦里 CMR 为 57.14%。黑斑羚 196 只、巴塔哥尼亚豚鼠 213 只病理记录里没有癌症。体重和预期寿命的模型只解释 CMR 方差的 0.78% 和 2.94%，正文给的是举例，不是一条可外推的公式。 |
| 补充表里实际有什么 | 仓库 data.csv 有物种、目、CMR、ICM、剩余寿命天数和食性。没有把 Sample、Deaths、knownDeaths 放进个人报告。性别表只有部分食肉目的 CMR_F 和 CMR_M。期刊补充表 PDF 是模型结果，这次没有拆成可相乘的回归系数。 |
| 代码仓库实际算什么 | code.R 拟合系统发育模型。仓库没有单独公布一套供个人体重使用的系数向量。CMR 列与 Neoplasia / knownDeaths 一致，例如猎豹 8/225。 |
| 同名的另一个项目是什么 | 更早的跨物种比较用最大寿命和患病率。这篇用的是动物园成年个体的癌症死亡比例。 |

110148、11840 和 191 留在这里，不写进个人报告。
