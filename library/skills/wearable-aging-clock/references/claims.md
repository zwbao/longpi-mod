# 论文、仓库、另一套同名东西

Nature Communications（2025），doi:10.1038/s41467-025-64275-4。全文用 pypdf 从 PDF 抽出。

| | 内容 |
| --- | --- |
| 论文声称 | PpgAge 用约 2,000 万段 60 秒 PPG 的自监督网络得到 256 维表示。健康参与者 n = 6,728，其中 80%（n = 5,355）训练，健康测试 n = 1,373，一般队列 n = 120,235。PpgAge gap 是 PpgAge 减去实足年龄。开头结果写健康队列 MAE 2.43 年（2.33–2.53）。Fig. 3：健康测试男性 MAE 2.42 年（2.30–2.54，n = 1,115），女性 2.45 年（2.22–2.71，n = 258）；一般队列男性 3.13 年（3.11–3.15，n = 77,501），女性 3.26 年（3.24–3.29，n = 42,734）。Fig. 3 说明分析限制在实足年龄 18 到 85 岁。实足年龄用出生年的 7 月 1 日近似。每段至少 30 个片段。 |
| 代码实际算 | `apple/ml-ppg-age-analysis` 的 `run_fit_age_model.py` 在合成嵌入上用 RidgeCV 拟合，并把年龄画成 18 到 90 的均匀随机数，`frac_train` 默认 0.75。它不包含 AHMS 的 256 维模型和岭回归系数。 |
| 同名的另一套 | 训练代码改编自另一篇 PPG 基础模型（Abbaspourazad 等，arXiv 2312.05409）。那是表示学习，不是这篇论文的年龄差。 |
