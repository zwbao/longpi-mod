# 论文、代码、另一套同名东西

Du 等，Nature Communications 17:9130（2026），doi:10.1038/s41467-026-76038-w。全文由本地 PDF 抽出，16 页。

| | 内容 |
| --- | --- |
| 论文声称 | OmniAge 收了 413 个衰老组学标志、12 类。有丝分裂时钟（包括 epiTOC1/2 和 stemTOC）与甲基化推算的克隆性造血代理指标、AdaptAge 相关；各队列没有测序测出的克隆性造血突变；低甲基化时钟并不一致。EPIC-Italy 队列 845 人被用来看肿瘤风险。正文抽文本没有给出可单独引用的相关系数或比值比。 |
| 这份 Skill 实际算 | epiTOC2 的 tnsc。对上且有数值的探针才进入均值，文件里没有的、写成空白或 NA 的都不填补。这与 `OmniAgePy` 里 `EpiTOC2.predict` 取交集、均值跳过 NaN 的做法一致。同一仓库的 R 函数在覆盖不到一半时返回空值，遇到 NA 会报错停止；这里不跟覆盖门槛，NA 按 Python 包跳过。探针名不分大小写；β 不在 0 到 1、同一探针出现两次（R 函数同样拒绝重复行名）、数值读不出时不算，退出码 3。有年龄时 irS = tnsc / 年龄，年龄要大于 0（与 R 函数一致）。 |
| 代码实际算 | 仓库还有其余时钟的系数。本命令不调用它们。 |
