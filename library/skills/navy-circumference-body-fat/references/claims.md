# 报告、附录、代码、同名的另一个东西

| | 内容 |
| --- | --- |
| 报告声称 | 海军原用的 Wright 等（陆战队）围度公式对海军人员偏差大，于是在男性 602 人、女性 214 人中用水下称重体密度做逐步回归，只留围度和身高：男性用腹围（肚脐）减颈围和身高，女性用腰围（最细处）加臀围减颈围和身高，都取对数，单位厘米；再用 Siri 公式换成体脂率。男性在另外 100 名海军人员中交叉验证，女性在 66 名加拿大军人和 80 名美国海军女性中交叉验证。 |
| 附录里实际有什么 | 附录 A 是按英寸排的现场查表（围度值 × 身高 → 体脂率整数）。男性表和印出的方程完全对得上；女性表在 15%–40% 段对得上，偏瘦和偏胖两端偏低，见 `contract.md`。 |
| 代码实际算什么 | 报告没有代码。本技能按印出的厘米方程和 Siri 公式实现，英寸只在读入时按 2.54 换成厘米。腰围身高比、腰臀比和国家标准分类按各自来源的切点实现。 |
| 同名的另一个东西 | “美国海军体脂公式”常被写成英寸的线性对数式（86.010、70.041、36.76；163.205、97.684、78.387），出自后来的国防部文件，不是这两份报告，本技能不用。VitaClaw 原技能把这组英寸式当成厘米式用，会系统性高估。IDF 2006 的中国人腰围切点（男 >90、女 >80 cm，见 WHO 2008 表 A2）和 WS/T 428-2013 的女性切点（≥85 cm）不同，这里只用国家标准。 |
