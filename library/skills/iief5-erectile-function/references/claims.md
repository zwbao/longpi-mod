# 论文、公开说明、代码、另一个项目

| | 内容 |
| --- | --- |
| 论文声称 | Rosen 等 1999 从 15 题的 IIEF 里选出 5 题（勃起功能和性交满意度），在 1152 名男性（1036 名勃起功能障碍、116 名对照）里用 ROC 找到 21 分切点（灵敏度 0.98，特异度 0.88），并分出五档严重程度，预测分档和「真实」分档的加权 kappa 为 0.82。 |
| 公开说明里实际有什么 | Rhoden 2002 摘要印出五档完整分界。de Donato 2022（CC BY）印出回忆期「过去 6 个月」和每题 1–5 分。 |
| 代码仓库实际算什么 | 原论文没有代码。VitaClaw 的 sexual-health-analyzer 只有 SKILL.md，没有脚本；它写每题 0–5、总分 0–25（和论文的 5–25 不一致），并把 8–11 分写成「需要医疗干预」，没有转诊门槛和心血管提示。STD 筛查、避孕、活动记录和跨模块关联都没有带过来。 |
| 同名的另一个项目 | 15 题的完整版 IIEF（Rosen 1997）有 0 分选项、四周回忆期和不同的分域计分，不能和 IIEF-5 混用。这里只用 Rosen 1999 的五档。 |
