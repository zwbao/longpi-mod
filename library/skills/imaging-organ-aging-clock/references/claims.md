# 论文、脚本、另一个项目

## 论文声称

Methods：七个器官是脑、心脏、体成分、肾、肝、胰腺和眼，用 1777 个影像表型，来自 11,000 名健康参与者。脑灰质和白质分开评估。年龄差是预测年龄相对实足年龄的差（Fig. 1 图注附近：defined as the difference）。Results：脑灰质年龄差与痴呆 HR = 1.81，SD = 5.46 年；脑白质年龄差与脑血管病 HR = 1.46，SD = 6.67 年。后文有一句把 6.67 年说成脑灰质，和前面紧挨 HR 的 SD 不一致，本报告不用那一句做个人标准化。这些 SD 随结局变化，不是每个人一个固定的 z 分母。Methods 还写了把实足年龄从预测年龄里回归掉。校正前、后，实足年龄对年龄差的斜率是：脑灰质 −0.34 与 −0.04，脑白质 −0.36 与 −0.04，心脏 −0.45 与 −0.02，体成分 −0.46 与 −0.04，肾 −0.89 与 −0.04，肝 −0.92 与 −0.06，胰腺 −0.91 与 −0.09，眼 −0.92 与 −0.07。回归的截距没有印出。Results 点名的血浆蛋白是 CHRDL2、ITIH4、LRRC37A2、SEMA3F、TIE1（脑），ABO、CLPS、GRP（胰腺），ERI1、MSRA、SPINK8（眼），LAMB1、UMOD（肾）。ADH4 出现在六个药物靶点或在研靶点里，同一段没有写它的器官。论文说共有 14 个血浆蛋白，Supplementary Table 25 没有随正文抽出，这里不补第 15 个名字。

## 代码实际计算

论文写代码在 https://github.com/hitrp/MultiOrganImagingAging/ 。克隆时仓库不存在。没有 IDP 权重，脚本不算 LASSO 预测年龄，也不套偏差校正，因为截距没有印出。它只在用户已经给出预测年龄时做减法。七个器官缺一就不把缺项当成 0 去平均。灰质和白质不并进这七个器官的平均。

## 同名的另一个项目

Oh 等人的血浆蛋白器官年龄和另一篇 MRI 多器官时钟不是这 1777 个影像表型的 LASSO。那些权重不能拿来填这个空仓库。
