Zhu 等，Nature Communications 17:528（2026），doi:10.1038/s41467-025-67223-4。全文由本地 PDF 抽出，14 页。

| | 内容 |
| --- | --- |
| 论文声称 | UKB-PPP 51,936 人、2,923 种蛋白。13 个器官：脂肪、动脉、脑、心脏、免疫、肠、肾、肝、肺、肌肉、胰腺、皮肤、胃。器官富集蛋白 1,799 个（每个器官 34 到 356）。无 ICD-10 记录的 7,217 人用于训练。弹性网在 11 个器官上最好；肾、胰腺、胃上树模型有过拟合，后续仍用弹性网。权重在 Supplementary Data 3。校正前预测年龄差与年龄的相关为 −0.90 到 −0.48，lowess 残差之后为 −0.021 到 0.025（Supplementary Fig. 4）。119 个位点，其中 27 个跨器官，554 个风险基因。摘要：心脏和肌肉衰老加速增加心衰风险，肾脏衰老与高血压有关，吸烟起始与肺、肠、肾、胃的衰老正向关联。 |
| 这份 Skill 实际算 | 用户点到的名字是否属于这 13 个器官，并附上摘要里写明的方向。Supplementary Data 3 已打开，列是 Organ、Feature、Weight，没有截距，所以不算器官年龄。 |
| 代码实际算 | `zrj1236/Organ_Aging_Model` 在模拟的 1,000×100 矩阵上做嵌套交叉验证。弹性网网格是 0.01 到 0.99，不是正文写的 0 到 1。随机种子 42。这不是 UKB 权重。 |
| 同名的另一套 | Oh 等 Nature 2023 的器官年龄时钟是另一篇。本文用他们的 lowess 校正，但位点表不是那篇的结果。这也不是血浆器官蛋白质时钟那一套。`zrj1236/Organ_Aging_Model` 是模拟数据上的交叉验证，不是这张权重表。 |
