# 论文、仓库、另一套同名东西

Wen 等，Nature Communications（2025），doi:10.1038/s41467-025-59964-z。全文读自 EuropePMC PMC12106725。

| | 内容 |
| --- | --- |
| 论文声称 | 274,247 名 UK Biobank 参与者的 107 个非衍生代谢物，五个系统：消化、肝、免疫、内分泌、代谢。健康对照 34,354 人，其中独立测试 5,000，其余 29,354 用于训练与交叉验证；至少一条 ICD 诊断的 239,893 人留在患者集。独立测试集 0.25 < r < 0.42，平均绝对误差大约 6 年。随后使用 Beheshti 年龄偏差校正。GWAS 405 个位点对（P < 5×10−8/5）。SBayesS 遗传力 0.09 到 0.18。免疫与肝的遗传相关 0.78±0.04。LDSC 截距 1.05。 |
| 代码实际算 | 构建清单里的四个地址是 mlni 0.1.4（年龄预测）、ukbnmr（代谢物质控）、LDSC（遗传相关）和 PRScs（PRS）。它们是通用依赖，不是这份 MetBAG 权重，本技能没有克隆。未校正年龄差在正文定义为预测年龄减去实足年龄；校正系数不在已读全文的数字里。 |
| 同名的另一套 | MEDICINE 门户（labs-laboratory.com/medicine）写着放有预训练模型。本技能没有下载该门户。mlni 也不是 MetBAG 系数文件。 |

这次核对：全文指向 MEDICINE 门户、Synapse 和 Zenodo 上的预训练模型。补充数据说明里没有带代谢物名字的系数。四个 GitHub 地址是通用工具。个人能算的是已给出的预测年龄减去实足年龄，这是校正前的差。
