| 论文声称 | 分析样本 1022 人，基线平均年龄 81 岁。衰弱是五项里至少三项：握力、八英尺步时、体质指数、疲劳、体力活动。疲劳两题来自 CES-D，各记 0 或 1，和为 0 到 2。相对振幅 RA = (M10−L5)/(M10+L5)。表 2 给出每 1 个标准差的风险比，幅度、周期长度变异、IS、IV、M10 的风险比在 1.21 到 1.41。代码在 https://github.com/pliphd/Actigraphy。 |
