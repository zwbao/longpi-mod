# 报告里用到的说法

这些句子和 `scripts/presets.py` 里的常量一致。

- 输入是原始细胞比例。
- 输入是对数转换后的表达，技能没有再取一次对数。
- 输入是原始 TCR 指标，性别按女为 0、男为 1。
- ptAge：没有算。Table S3 有系数，缺每个特征在训练集上的最小值和最大值。
- immAge：没有算。Table S3 有系数，缺每个特征在训练集上的最小值和最大值。
- bulk-immAge：没有算。系数不在 Table S3。
- 读不了这种格式，请改交表格。

下面几条正文没有写死，个人报告不套用：

- `01_cellprop.R` 用 `as.numeric(as.factor(gender)) - 1`，水平顺序取决于性别字符串怎么排序。报告固定女为 0、男为 1。
- `04_combind.R` 对整张表取一个最小值和一个最大值。Table S3 没有这些数，所以不算 ptAge 和 immAge。
- `06_pace_analysis.R` 取排序后两端各 21 人。一个人的报告不算衰老步伐。
