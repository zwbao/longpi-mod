# 论文、公开说明、代码、另一个项目

| | 内容 |
| --- | --- |
| 论文声称 | Adan 和 Almirall 1991 从 Horne-Östberg 19 题 MEQ 里选出 5 题组成 rMEQ，在不同作息和年龄的成人样本里检验，并给出五档切点。 |
| 公开说明里实际有什么 | Belfry 2020、Gooderick 2025（CC BY）印出 4–25 和五档，注明出自 Adan 和 Almirall 1991。Hwang 2024 表 1 印出每题选项分；Danielsson 2019 印出第 5 题记 0–6。 |
| 代码仓库实际算什么 | 原论文没有代码。VitaClaw 的 circadian-rhythm-optimizer 只有 SKILL.md，没有脚本；题目组成和 rMEQ 不一致（缺 MEQ 第 10 题），另有没有出处的 DLMO 估算和作息处方。 |
| 同名的另一个项目 | 19 题 MEQ（16–86 分，另一套切点）、儿童青少年版 rMEQ-CA、慕尼黑时型问卷 MCTQ（按实际睡眠中点）都不是这个量表，分数不能互换。库里的 wearable-circadian-aging-biomarker 和 circadian-frailty-older-adults 用活动记录测实际节律，也不是偏好问卷。 |
