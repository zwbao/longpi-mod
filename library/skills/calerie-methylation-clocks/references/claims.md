# 论文、仓库、另一套同名东西

Waziry、Ryan、Belsky 等，Nature Aging 3:248–257（2023），doi:10.1038/s43587-022-00357-y。全文从本地 PDF 读过。仓库 `danbelsky/CALERIE_ClocksAnalysis` 克隆在 `/tmp/paper-code/p63`。

| | 内容 |
| --- | --- |
| 论文声称 | 220 人随机（限食 145，对照 75），甲基化分析 197 人。处方 25% 限食，实际平均 11.9%（标准误 0.7）。DunedinPACE 的意向性治疗 d：12 个月 −0.29（−0.45，−0.13），24 个月 −0.25（−0.41，−0.09），对应节奏放慢 2–3%。PC PhenoAge：12 个月 −0.03（−0.19，0.12），24 个月 0.05（−0.11，0.20）。PC GrimAge：12 个月 −0.04（−0.16，0.07），24 个月 0.05（−0.07，0.17）。10% 以上限食时 DunedinPACE d 均为 −0.33；不足 10% 为 −0.19 和 −0.14。工具变量 20% 限食：12 个月 −0.43（−0.67，−0.19），24 个月 −0.40（−0.67，−0.12）。显著性界 P < 0.005。 |
| 这份 Skill 实际算 | 把用户给出的三个时钟测量写在这些已发表 d 旁边。不把 d 换成这个人的年龄变化。 |
| 同名的另一套 | 仓库里的 Stata 脚本（`CALERIEClockAnalysis.do` 等）重跑试验的意向性治疗和中介，不给试验外的人计算 DunedinPACE。DunedinPACE 的 CpG 权重在另一套时钟实现里，不在这个仓库。 |
