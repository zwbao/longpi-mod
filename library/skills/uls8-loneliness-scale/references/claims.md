# 论文、公开说明、代码、另一个项目

| | 内容 |
| --- | --- |
| 论文声称 | Hays 和 DiMatteo 1987 从修订版 UCLA 孤独量表（ULS-20）的探索性因子分析里挑出 8 道在第一因子上载荷高的题，组成 ULS-8，认为它可靠、有效，比 4 题短版更能代替 20 题版。摘要还说孤独与所测的六种健康行为不相关。 |
| 公开说明里实际有什么 | Xu 等 2018（CC BY）印出计分：第 3、6 题反向，每题 1–4，总分 8–32。没有切点。 |
| 代码仓库实际算什么 | 原论文没有代码。VitaClaw 的 social-health-tracker 只有 SKILL.md，没有脚本；它把第 4 档写成 Always，另加了没有出处的四档切点、0–100 的社交健康综合分和邓巴圈子。这里只保留量表本身的计分。 |
| 同名的另一个项目 | UCLA 孤独量表还有 20 题版（ULS-20、第 3 版）和 3 题版（Hughes 2004），计分和范围不同，不能混用。中国老人和青少年的研究建议去掉第 3、6 题的 ULS-6；这里仍按原 ULS-8 计分。 |
