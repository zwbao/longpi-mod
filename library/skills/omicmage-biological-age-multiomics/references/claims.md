# 论文、代码、另一套同名东西

Chen 等，Nature Aging 6:722–737（2026），doi:10.1038/s43587-026-01073-7。全文由本地 PDF 抽出，27 页。

| | 内容 |
| --- | --- |
| 论文声称 | MGB 最终 31,264 人、19 个临床变量（训练 21,885，测试 9,379）。方法段写出 EMRAge = 9.70296 × Xβ + 51.68254，变量未标准化。Xβ 的 19 个系数在 Supplementary Table 3，不在 PDF 正文，也不在已发布的脚本里。测试集与年龄的 Pearson ρ 为 0.76，训练集 0.75。测试集全因死亡 HR 4.53（Fig. 2b）。DNAmEMRAge 用 1,097 个 CpG，训练 MAE 8.33 年，测试 MAE 8.50 年（Fig. 3c）。Fig. 4 写明最终保留 16 个蛋白、14 个代谢物、10 个临床表观代理。临床列能读清 9 个：尿素氮、肌酐、肝白蛋白、HbA1c、红细胞分布宽度、血红蛋白、葡萄糖、红细胞压积、碱性磷酸酶。蛋白列去掉重复的 PON1、重复的 CPB2 和空白子弹后，能读清 13 个，其中包括多功能蛋白聚糖核心蛋白、组蛋白 H2B type 1-K、CHRDL1、胰核糖核酸酶和 Hsc70 相互作用蛋白。代谢物 14 个都能读清。 |
| 这份 Skill 实际算 | 用户测量名是否落在上述读清的特征上。第一段另写 All of Us 方法段点名的 16 个 EMRAge 输入对上了几项，这 16 项不另开一份名单。`emr_age` 只是公式函数，报告不调用它，因为没有 Xβ 的系数。 |
| 代码实际算 | `LaskySuLab/OMICmAge` 训练弹性网和 Cox，但系数存在未随仓库发布的 RData（`DNAmEMRAge_model.RData`、`EMRAge_v1.RData`）。脚本不会在没有这些文件时给出年龄。 |
| 同名的另一套 | TruDiagnostic 对外报告的 OMICmAge 是商业实现。PhenoAge（Levine）用的是 CRP、肌酐、白细胞、淋巴细胞百分比和平均红细胞体积，论文把它们用于对照，不是 EMRAge 的 19 变量。 |

Fig. 4 蛋白列在 PDF 抽文本里有重复和空行。没有读清的 3 个蛋白名和 1 个临床名没有补进预设。多功能蛋白聚糖核心蛋白不是核心蛋白聚糖。
