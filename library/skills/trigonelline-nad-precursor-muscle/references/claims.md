# 论文、代码、另一套同名东西

Membrez 等，Nature Metabolism（2024），doi:10.1038/s42255-024-00997-x。全文来自 Europe PMC PMC10963276。JSON 里没有 GitHub。

| | 内容 |
| --- | --- |
| 论文声称 | 肌少症血清葫芦巴碱更低，并与 ALMI、握力和步速正相关（Fig. 1）。对照肌管 EC50 = 315 µM，FK866 处理下挽救 NAD+ 的 EC50 = 110 µM。进入 NAD+ 依赖 NAPRT，不依赖 GPR109A。小鼠灌胃或饲料按无水葫芦巴碱 300 mg/kg。老年小鼠握力和抗疲劳提高，最大强直力没有改变。Bushehr 复制队列 n = 186。 |
| 这份 Skill 实际算 | 原样记下用户给出的血清葫芦巴碱。现用药只有和这次记下的葫芦巴碱同名时才对上名单。不把 EC50 或 300 mg/kg 换成个人剂量，也不把另外四种前体自动放进名单。 |
| 同名的另一套 | 咖啡和葫芦巴里的葫芦巴碱含量数据库。那不是这篇的 NAD 示踪实验。 |

主文没有给出用于划分肌少症的血清浓度界值，也没有给出 Fig. 1 的相关系数数字，所以这两项不编。
