# 论文、仓库、另一套同名东西

Nature Aging（2025），doi:10.1038/s43587-025-00925-y。全文用 pypdf 从 PDF 抽出。

| | 内容 |
| --- | --- |
| 论文声称 | HFRS 按先前方案用 109 个加权 ICD-10 编码求和。每个编码的权重在 0.1 到 7.1。编码和权重列在 Supplementary Table 18。分组：低（<5）、中间（5–15）、高（>15）。主分析使用 30 岁起到随访结束的编码。痴呆在公式里权重最高，因此另做了去掉痴呆权重的敏感性分析。GWAS 用 SAIGE。 |
| 代码实际算 | 清单里的 `FINNGEN/saige-pipelines` 是 FinnGen 的通用 SAIGE 流程，不是 HFRS 求和。本技能没有克隆它。诊断权重来自 Supplementary Table 18，每个编码只加一次。表里把 M48 标成仅作次级编码，印出的权重仍是 0.5，用户列出 M48 时计入。 |
| 同名的另一套 | 文中对照的衰弱指数（FI）和衰弱表型（FP）是别的衰弱定义。SAIGE 是广义混合模型工具，不是衰弱评分本身。 |
