# 论文、脚本、另一个项目

## 论文声称

血液样本 107 份，共同 CpG 3,089,098 个（Results，Fig. 1）。其中 279,990 个与年龄相关，Bonferroni 之后剩下 758 个（Fig. 1g,h）。时钟是 26 个 CpG 的加权甲基化加上截距 3.133 年（Results）。权重在 Supplementary Data 4。Fig. 2d 上相关最负和最正的时钟位点 r 分别是 −0.7 和 0.73。Results 保留 12 个时钟相关基因：Tert、Neurl1b、Mab21l2、LOC110349245、Lrba、Cacna1e、Shank1、Bahd1、Prpf19、Pcdh7、Naa30、LOC110346999。Cartpt 的权重是 0.02，论文因此不把它算作时钟相关基因。Fig. 4 把年龄除以最大寿命，三个物种用的是 31、4 和 122.5 年。下降位点和上升位点的趋势线相交在 11.87、1.66 和 70.69 年，相对年龄是 0.383、0.414 和 0.577。这是三个物种曲线的交点，不是把任意实足年龄换成另一个物种的公式。

## 代码实际计算

JSON 里的 GitHub 是 civisanalytics/python-glmnet。Methods 写明用它做弹性网，alpha = 0.5，n_splits = 10。Fig. 2b 的图注写的是 5 折，和 Methods 的 10 折不是同一句，这里不合并。python-glmnet 是求解器，不是裸鼹鼠权重。

Supplementary Data 4 是文章页上的 `41467_2022_27959_MOESM6_ESM.xlsx`（Clock1 表）。表里一行是 Interception 3.13349944282111，另外 26 行是位点权重。正文写的 3.133 是这个截距的四舍五入。个人报告在 26 个位点都给出、且甲基化在 0 到 1 时，用这张表做加权和。缺位点不填 0。实足年龄仍除以 Fig. 4 的最大寿命。12 个基因只列名字，不用截距单独冒充甲基化年龄。
