# 论文、补充表、代码、另一套同名东西

Zhao 等，Nature Communications（2025），doi:10.1038/s41467-025-59883-z。全文由本地 PDF 抽出，18 页。

| | 内容 |
| --- | --- |
| 论文声称什么 | 肥胖相关骨关节炎里，软骨、破骨细胞和干细胞伴随 DNA 损伤。p53–AKT–FOXO3 被写成这条反应的主线。关节腔给予表达 FOXO3 的慢病毒减轻高脂饮食小鼠的软骨退变。高脂条件下 Col2a1 下降、Mmp13 上升。FOXO3 过表达后 Gadd45a 升高。成熟破骨细胞里 FSP1、GPX4、SLC7A11 下降。图 3 定量的 n = 15。实验里用过 Pifithrin-β、MK-2206、ruxolitinib 和 Ferrostatin-1，这些是实验处理，不是基因名单。 |
| 补充表里实际有什么 | 期刊页的补充信息 PDF 被标为 supplementary information。正文写引物在 Supplementary Table 1。没有一份人类变异系数表，也没有截距列。这次个人读出没有打开引物表，因为引物序列不能乘到基因型上。不把「没打开引物」写成「论文没公布基因名」；基因名在正文。 |
| 代码仓库实际算什么 | 论文 Data availability 只说数据在正文和补充信息里，没有 Code availability，没有给出代码仓库 URL。 |
| 同名的另一个项目是什么 | 人类 FOXO3 长寿 SNP（例如与寿命相关的常见变异）是另一套文献。这篇是小鼠和细胞里的肥胖骨关节炎实验，不是那套基因型权重。 |
