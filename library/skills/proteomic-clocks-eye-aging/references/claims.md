## 论文声称什么

三个队列共 55,028 人。ProAge 在训练中的 MAE 是 2.23 年，测试 MAE 是 2.36 年；五折里非零系数的蛋白数为 2,139 到 2,190。心代谢面板时钟 cProAge 的折外 MAE 是 3.25 年。心代谢面板 226 个蛋白里有 166 个（73.4%）在外部队列重复了非零系数的方向。Methods 写明：加速蛋白年龄是把实际年龄对蛋白年龄回归后的残差，正值表示加速；这与预测年龄减实际年龄不是同一个量。GC-IPL 与 ProAgeAccel 的关联是每 1 个标准差 β = −0.15（95% CI −0.25 到 −0.04）。精简模型相对全模型与实际年龄的相关大约少 5%，实验成本大约降 90%。这些是队列结果。正文没有列出蛋白系数。

## 代码实际算什么

JSON 没有方法仓库。本技能不估计弹性网系数，也不计算回归残差。名单只包含用户已经给出的 ProAge 或 cProAge。

## 同名的另一个项目

作者此前用眼底照片做的深度学习眼龄时钟不是这个血浆蛋白时钟。本技能不把影像年龄当成 ProAge。
