# 论文、补充表、代码、另一套同名东西

Civiletto、Brunetti、Lizzo 等，Nature Aging（2025），doi:10.1038/s43587-025-00957-4。前二十页和数据可用性用本地 PDF 读过。MOESM3 已打开。

| | 内容 |
| --- | --- |
| 论文声称 | 试点库 240 个分子，七个命中里点名神经酰胺、calpeptin 和视黄酸。食物来源库在 10–250 µM 筛选，百里香酚和香芹酚最强。香芹酚从 50 µM、百里香酚从 10 µM 起效应明显。百里香酚硫酸酯和葡萄糖醛酸苷仍能诱导自噬。牛至精油含香芹酚、对伞花烃和百里香酚。SAMP8 小鼠灌胃 20 mg/kg/天，每周 5 天，共 12 周，从 8 月龄开始。Fig. 7a：每组 n = 15。骨骼肌泛组织时钟大约低 20%（P = 0.033）。转录组 GEO 为 GSE298195 和 GSE298196。甲基化阵列是 HorvathMammalMethyl40，原始数据向 Clock Foundation 索取。 |
| 补充表实际有什么 | MOESM3 的 Table 2 是 57 个天然分子。列有 Rank、Bioactives、CAS，以及 10、50、100、250 µM 下、有或没有 NH4Cl 时的 log2 相对 LC3 面积均值、SEM 和 N。香芹酚排第 1，百里香酚排第 2。没有名为 Emax 的列，排名在 Rank 列。Table 1 是药物库的排名，Previous report 列只填了视黄酸、calpeptin 和神经酰胺三行。没有标出正文所说另外几个试点命中的列。 |
| 代码实际算 | 斑马鱼成像代码在 https://github.com/giulializzo/zebrafish_high_content_imaging 。论文写基因表达和甲基化定量没有新代码。本技能不算表观遗传年龄，因为缺 CpG 权重列，也不把灌胃剂量写成用法。 |
| 同名的另一套 | 雷帕霉素是成像流程的阳性对照，不是这张食物来源名单上的新命中。Clock Foundation 的哺乳动物时钟不是本技能能重算的权重表。 |
