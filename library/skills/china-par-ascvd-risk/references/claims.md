# 论文、补充表、代码、另一套同名东西

Yang 等，Circulation 134:1430–1440（2016），doi:10.1161/CIRCULATIONAHA.116.022367。全文和补充材料读自官方站点的 PDF（https://www.cvdrisk.com.cn/uploadedFile/20171227114818843.pdf）。期刊页面这次返回 403。数值的来源、推导和核对见 `contract.md`。

研究设计：前瞻队列，用来建立和验证风险方程。对象：中国成人。

| | 内容 |
| --- | --- |
| 论文声称 | 推导队列是两个按统一方案随访的前瞻研究：InterASIA（2000–2001 年建立，35–74 岁）和 China MUCA（1998，35–59 岁）。两项研究共 27,020 人，24,334 人完成随访，排除后 21,320 人用来推导，平均随访 12.3 年，1,048 人首次发生动脉粥样硬化性心血管病。外部验证用另外两个队列：China MUCA（1992–1994）14,123 人和 CIMIC 70,838 人。所以是「两个队列推导、两个队列验证」，不是四个队列一起建立方程。男性 C 统计量 0.794，女性 0.811。 |
| 补充表里实际有什么 | 补充表 1 是男女分开的方程参数和计算示例（系数、系数×值、人群均值、基线生存率）；补充表 2 是个人 10 年风险的计算式；补充表 3、4 是两个验证队列的基线特征。系数只印到两位小数，女性基线生存率只印到 0.99，推导方法见 `contract.md`。 |
| 代码仓库实际算什么 | 论文没有给出代码仓库。 |
| 同名的另一套 | 美国的 Pooled Cohort Equations 是论文拿来比较的另一套方程，不是 China-PAR。2019 年《中国心血管病风险评估和管理指南》采用 China-PAR 做分层。 |
| 利益冲突 | 论文声明无（Disclosures: None）。资助来自科技部课题（2006BAI01A01、2011BAI09B03、2011BAI11B03）。 |
