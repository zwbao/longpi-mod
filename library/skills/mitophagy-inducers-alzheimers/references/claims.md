# 论文、补充表、代码、另一套同名东西

Xie、Zhuang、Niu、Ai 等，Nature Biomedical Engineering（2022），doi:10.1038/s41551-021-00819-5。前二十页和文末方法用本地 PDF 读过。MOESM3 已打开。

| | 内容 |
| --- | --- |
| 论文声称 | 预训练集 19.9 million 分子。已知线粒体自噬诱导物 14 个（Supplementary Table 1）。Macau Library 正文写 3274 个，方法里写 3724 个。相似度 s = v·w，截断 θ = 0.75，选出 18 个（Supplementary Table 2）。其中 8 个在 10 μM 的细胞实验里诱导线粒体自噬：槲皮素 T-2174、槲皮素二水合物 T-6630、他克莫司 T-2144、子囊霉素 T-2481、异鼠李素 T-2836、Pinostilbene T-3755、山奈酚 T-2177、丹叶大黄素 T-3776。槲皮素、山奈酚、丹叶大黄素在线虫神经元里也诱导。山奈酚和丹叶大黄素改善 Aβ 线虫的记忆读出。体外命中率写为 44%（8/18）。小鼠灌胃写为 100 mg/kg/d。 |
| 补充表实际有什么 | MOESM3 三个工作表：1D similarity、2D similarity、3D similarity。列是 ID 和 18 个文库编号的两两相似度，没有化合物名称列，也没有相对 14 个已知诱导物的向量 v、w。正文说 18 个分子的详情在 Supplementary Fig. 1 和 Table 2。没有名称的编号是 T0579、T2910、T0610、T0879、T2879、T1723、T3814、T3S1068、T7052、T3843。 |
| 代码实际算 | 论文写代码在专利审查中，向通讯作者索取，没有公开仓库。本技能不算 s = v·w，不把实验浓度写成用法。名单只用正文写出名字的八个细胞实验诱导物。 |
| 同名的另一套 | Mol2vec 原论文和 ChEMBL、ZINC 不是这份筛选的命中名单。文中提到的社区黄酮醇队列 921 人来自引用 63，不是这项实验的样本量。 |
