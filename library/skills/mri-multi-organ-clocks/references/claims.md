# 论文、仓库、另一套同名东西

Nature Medicine（2025），doi:10.1038/s41591-025-03999-8。全文读自 EuropePMC PMC12823390。构建清单的 github 为空。

| | 内容 |
| --- | --- |
| 论文声称 | 七个 MRIBAG：脑、心脏、肝、脂肪、脾、肾、胰腺。MULTI 313,645 人。脑用 119 个灰质体积，心脏 80 项，脂肪 16 项，肝 4 项，肾、脾、胰腺各 3 项。保留测试集 n = 500，校正前 r 从 0.23 到 0.77，平均绝对误差大约 5 年。年龄差是预测年龄减去实足年龄，再用 Beheshti 校正。ProWAS 603 个关联（P < 0.05/2,923/7），其中肾 301 个。MetWAS 758 个：脾 199、脂肪 196、心脏 139、脑 97、胰腺 57、肝 51、肾 19。GWAS 53 个位点对。九个可成药基因的名字不在已读正文的这一段里。 |
| 代码实际算 | 构建清单没有仓库，所以没有克隆。代码可用性写 MRIBAG 由 mlni 0.1.2 和 0.1.5 生成，图和代码在 Zenodo 15857817。本技能没有下载 Zenodo，也没有读到 LASSO 或支持向量回归的系数。 |
| 同名的另一套 | 同一组的 MetBAG（代谢组五个系统）和 ProtBAG 是别的时钟。mlni 是通用年龄预测库，不是这七个 MRIBAG 的权重文件。 |

这次核对：补充压缩包里的 LASSO 系数和截距没有影像指标名字，支持向量机权重同样对不上特征名，所以没有乘到个人测量上。个人能算的是已给出的预测年龄减去实足年龄，这是校正前的差。
