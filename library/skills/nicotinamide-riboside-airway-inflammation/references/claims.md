# 论文、仓库、另一套同名东西

Norheim 等，Nature Aging（2024），doi:10.1038/s43587-024-00758-1。全文读自 EuropePMC PMC11645284。代码可用性写明没有为本试验新写代码。

| | 内容 |
| --- | --- |
| 论文声称 | 稳定期慢性阻塞性肺病 40 人，烟酰胺核糖每天 2 克（每次四粒 250 毫克，早晚）共 6 周，再随访 12 周。主要结局是痰液白细胞介素-8。第六周组间估计差 −52.6%（95% 区间 −75.7% 到 −7.6%，P = 0.030）。第 18 周 −63.7%（−85.7% 到 −7.8%，P = 0.034）。全血 NAD+ 升高两倍以上，血浆白细胞介素-6 无变化。样本量计算假设基线 21 ng/ml，标准差 5.74。纳入年龄至少 60 岁。 |
| 代码实际算 | 没有原始代码。本技能只在用户同时给出基线和第六周时计算 (第六周 − 基线) / 基线。试验估计差、全血 NAD+ 和血浆白细胞介素-6 的队列结论留在本文件，不写进个人报告。 |
| 同名的另一套 | 方法里引用的、在老年人中用 1 克烟酰胺核糖看血液炎症标志物的先前工作，不是这个 2 克气道试验。 |
