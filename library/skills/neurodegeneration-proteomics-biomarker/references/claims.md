# 主张

全文已读：EuropePMC PMC12353841，本地 PDF 为同一篇。

## 论文声称什么

GNPC V1 聚焦 AD、PD、ALS、FTD 和衰老，18,645 名参与者、23 个队列、31,083 份血浆血清和脑脊液样本、35,056 次蛋白检测，约 2.5 亿次蛋白测量。差异分析的一个子集是 5,879 人。至少六个队列里在 AD 血浆中升高的蛋白包括 ACHE、SPC25、LRRN1 和 CTF1。GDF2 和 APOB 被写成效应量较大，分别在五个和四个队列里独立显著。至少六个队列里更低的包括 VAT1、GPD1、ARPC2 和 PA2G4。五个队列里下降的包括 RPS12、NPTXR 和 NT5C。SPC25、LRRN1 和 CTF1 也被写成升高并反映 APOE。额颞叶痴呆中下调的包括 NPTXR、APLP1 和 HS6ST3。跨诊断段落点名 ACHE、NPTXR、EPHA4、CNTFR、MSMP 和 KLK3。与 APOE ε4 相关的包括 SPC25、LRRN1、S100A13 和 NEFL。与 AD 诊断相关且不依赖 ε4 的包括 NPTXR 和 GDF2。这些句子没有给出可相乘的效应量。

## 代码实际算什么

JSON 没有方法仓库。数据在 AD Workbench 上，本技能不登录、不下载。名单只做上述蛋白名字的覆盖，不估计回归系数。

## 同名的另一个项目

各成员队列自己的蛋白论文，以及 SomaScan 或 Olink 的平台软件，不是 GNPC V1 这份调和数据的差异分析结果。
