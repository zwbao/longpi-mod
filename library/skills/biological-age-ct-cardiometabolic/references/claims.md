| 这份 Skill 实际算 | 把用户数值与 Table 2 同一性别、同一年龄段的两个中位数做距离比较。更靠近死亡中位数的项目按 Table 1 的 IPA drop 从大到小写入名单。中位数相同或距离相同的不写入。不算 Cox 线性预测，不算生存率，不算 CT 生物年龄。 |
