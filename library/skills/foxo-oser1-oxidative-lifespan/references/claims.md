Song 等，Nature Communications（2024），doi:10.1038/s41467-024-51542-z。全文由本地 PDF 抽出，18 页。补充信息 PDF 已打开，表 5 和表 6 按版面坐标读出。

| 论文声称什么 | OSER1 是 FOXO 靶基因。过表达延长蚕、线虫和果蝇寿命，敲低则缩短。人类部分：OSER1 上 49 个常见 SNP、7 个独立连锁群（r2 < 0.1）。其中两个 SNP 来自一个连锁群，P < 0.0024（按 21 次检验校正：7 个连锁群、两个表型、长寿一个队列、绝经年龄两个队列）。另五个 SNP 来自另一个连锁群，名义 P < 0.05。绝经年龄没有达到校正阈值。补充表 4 的长寿个体 N = 863。区域为 chr20:42,823,581-42,844,546（含上游 5,000 bp 和下游 1,000 bp）。 |
| 补充表里实际有什么 | 补充信息 PDF（`41467_2024_51542_MOESM1_ESM.pdf`）里，表 5 是 49 个 SNP，列有 SNP、Chr、Pos、N cases、N controls、Minor Allele、Major Allele、MAF、MAF cases、MAF controls、LD group。表 6 标题是七个与人类长寿名义或显著关联的 SNP，读出的列是 SNP、OR、SE、95% CI、P。达到更严阈值且 LD group 为 4 的是 rs1474753（OR 1.456，P 0.0004）和 rs6031460（OR 1.291，P 0.001）。名义关联且 LD group 为 2 的是 rs6031450、rs6073366、rs9875、rs6073369、rs13044950，OR 都大于 1。表 7 是绝经年龄的回归系数，不是长寿结局，个人读出没有把它当成寿命权重。Supplementary Data 1–7 的 xlsx 是转录组和蛋白质组，不是 SNP 系数。 |
| 代码仓库实际算什么 | 论文的 Data availability 没有 Code availability，没有给出代码仓库 URL。 |
