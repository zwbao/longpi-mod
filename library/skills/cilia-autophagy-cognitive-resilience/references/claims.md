# 论文、补充表、代码、另一套同名东西

Rivagorda、Romeo-Guitart 等，Nature Aging（2025），doi:10.1038/s43587-024-00791-0。前二十页和数据可用性用本地 PDF 读过。

| | 内容 |
| --- | --- |
| 论文声称 | 骨钙素通过海马神经元上的 GPR158 带动自噬。GPR158 有五个 VxPx 基序，与 ACIII 共定位；培养的海马神经元里大约 75% 能在纤毛上看到 GPR158。核心蛋白包括 TULP3、KIF3A、IFT20、IFT88。年老海马纤毛形态异常，核心蛋白下降；把水平补回去可以改善自噬和认知读出。体内实验用雄性小鼠。Fig. 8 一类图注写 3 个月 n = 8，16 个月 n = 7。蛋白质组原始数据在 PRIDE PXD056975。 |
| 补充表实际有什么 | 本次没有打开期刊 xlsx。正文没有把纤毛长度或血清骨钙素映射到认知分数的系数列。 |
| 代码实际算 | 蛋白质组分析代码在 Dryad https://doi.org/10.5061/dryad.dfn2z35bh 。本技能不跑那套差异蛋白分析，也不把动物给药写成用法。名单是正文点名的轴成员。 |
| 同名的另一套 | 同一组先前关于骨钙素或生长分化因子的工作是引用，不是这根纤毛轴的系数表。 |
