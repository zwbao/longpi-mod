| 论文声称 | 从 1,656 篇里留下 15 篇，得到 125 个基因。方法写明不纳入 CDKN2A、CDKN1A、RELA、NFKB1。图二：小胶质细胞 GSE145265，常规集合 p = 0.1565，SenMayo p = 0.0052，n = 4。图三骨衰老 p = 0.0023（n = 25）；AP20187 清除后 p = 0.0054（n = 29）。图四、图五取 SenMayo 最高的 10% 细胞。队列 A 年轻与绝经后各 19 人。NCT02848131 是达沙替尼 100 mg/日加槲皮素 1000 mg/日，共三天，不是本报告的指令。 |
